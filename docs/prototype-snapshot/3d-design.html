How we work

Details, details, details

Twenty-five years in the consulting engineering world means hundreds of detailed plans for civil and mechanical firms, and the habits that come with them. Those habits are the reason your part fits the first time.

Every project that comes through the door gets treated like one of our own, on the old rule of measure twice, cut once. Getting it right on the screen is far cheaper than getting it wrong in material.

Cutting edge tools

The software has kept up. So have we.

Autodesk tools have changed a lot over twenty-five years, and we have used most versions along the way. That means modern modeling when a project calls for it, and none of the guesswork when a drawing has to be read by somebody else.

Bring a sketch on paper, a photo, a broken original, or a description you have been carrying around for years. Any of those is a starting point.

Four ways a project usually starts

An existing part

Common questions

Good to know

I only have a rough idea. Is that enough?
Yes. Most projects start that way. A conversation and a few questions usually get us to something we can draw.
Do I own the design when it is done?
The model is for your project. Standard file formats are available on request.
Can you improve a part rather than copy it?
That is usually the better plan. If a part broke in the same place twice, copying it exactly just delays the next failure.
Do you design for printing only?
No. Printing is one way to make a part. The model can be built for whatever process suits it.
Have an idea?

Let us draw it up.

Describe what you are picturing. If it is easier to show us, send a photo of the sketch or the original part.
